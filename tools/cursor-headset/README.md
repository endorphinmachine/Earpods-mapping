# Cursor 耳机媒体键映射（AutoHotkey v2）

**仅 Cursor 前台时拦截。**

## 键位

| 耳机 | 动作 | 按键 |
|------|------|------|
| 音量+（按下/松开） | 语音开 / 关 | `Ctrl+Shift+Space` |
| 播放/暂停 | 发送给 Agent | `Ctrl+Enter` |
| 音量减 | 停止生成 | `Ctrl+Shift+Backspace` |

音量加**只有录音**，无短按「接受」。

## 使用

1. 安装 AutoHotkey v2  
2. 退出旧脚本后运行 `cursor-headset.ahk`  
3. 可选：`install-autostart.ps1` 开机自启
